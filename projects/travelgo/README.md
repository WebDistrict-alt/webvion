# TravelGo

Demo travel platform: destinations, interactive world map, hotels with booking, AI trip planner, trip builder, experiences and a personal account.

Static HTML, CSS and vanilla JavaScript. Maps use Leaflet with Esri tiles, photos come from Unsplash. Sign-in, bookings and saved trips are demo features stored in the browser's localStorage.

## Run locally

```bash
python -m http.server 5250
```

Then open http://127.0.0.1:5250.
